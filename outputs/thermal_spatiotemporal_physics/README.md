# Four-frame history sensitivity

This run uses lags of 0, 10, 25, and 50 ms. It is retained as a sensitivity
check for the primary two-frame experiment in
`../thermal_spatiotemporal_physics_short`.

The additional history modestly informs the cooled trail but makes the current
endpoint posterior too narrow. The two-frame version has lower field error and
hot-region CRPS for the combined physics-mean and space-time method.
