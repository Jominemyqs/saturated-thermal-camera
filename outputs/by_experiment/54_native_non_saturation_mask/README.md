# Budgeted native non-saturation-mask pilot

## Question and scope

Does observing only non-saturation at otherwise unused locations help native,
non-advective C? This is output **54**, generated by
[driver 58](../../../scripts/58_thermal_native_non_saturation_mask.py), not an
extension or overwrite of output 53. Only the two development cases
DiagonalScanPath_8 and SpiralScanPath_13 were tested. No held-out inference,
parameter fitting, source reinterpretation, advection, or time integration was
performed.

The pre-experiment [code-reading ZIP](../../review_packages/native_C_code_snapshot_2026-10-08.zip)
contains unchanged historical code and calibration/configuration artifacts, with
relative paths and SHA-256 manifest. It is not a standalone runnable repository.
It intentionally excludes this new helper/driver, reviewer documentation,
datasets, and inference caches. No email was sent.

## Frozen construction

- Native prediction geometry has 6,275 surface nodes per case. Physical-area
  weights and the fixed hottest 1% **of area** come directly from output 52.
- `O_star = numerical_candidates UNION observed_reference_saturation` is retained.
  Its locations contribute a numerical reading when unsaturated, otherwise a
  lower noisy-signal bound. Reference C0 reproduces output 52 C exactly.
- Geometry-only farthest-point sampling selects 256 nodes outside `O_star`.
  The first node is nearest the eligible bounding-box center; subsequent nodes
  maximize distance from selected nodes. One common coordinate normalization
  preserves physical Euclidean geometry; distances are rounded to 14 decimal
  places and ties use the lowest node ID. There is no selection RNG, truth,
  omitted temperature magnitude, or error-based selection.
- The eligible pool is verified reference-unsaturated and still unsaturated at
  320/325 K under the identical cached pre-clipping realization. IDs are frozen
  across ceilings. This is a **sampled mask**, not full-mask inference.
- Previous hybrid draws/mean, deterministic physics mean, camera noise,
  coefficients, native geometry, area weights, and total predictive prior are
  reused from output 52. Previous inference was not rerun.
- The prior is `K_prior = Q_dt + H H^T`, where `H` contains the existing propagated
  previous deviations divided by `sqrt(M_previous - 1)`. Overlapping added-node
  covariance blocks are checked against baseline blocks. Inherited and total
  marginal prior variances reproduce the saved arrays exactly.
- Camera generation SD is 0.25 K; current likelihood SD is **0.50 K in every arm**.
  The 61 x 41 propagation grid, floor/boundary/interpolation rules, alpha, beta,
  gamma, gradient threshold, forcing settings, and numerical jitter are unchanged.
  Native inputs still do not mean interpolation-free 3D propagation.

| Arm | Added information at the identical 256 locations |
|---|---|
| C0 | None |
| Cmask | Only the noisy signal event `Z < c` |
| Cnumeric | Actual noisy numerical readings; no additional flag |

The isolated [mixed-bound helper](../../../src/native_mask_pilot.py) conditions
jointly on numerical observations, then sign-transforms noisy inequalities into
lower bounds for the existing reflected-HMC sampler. For upper bounds the factor
is `Phi((c - T) / 0.50)`. Signs transform means, covariance, and thresholds;
sampled signals are transformed back before prediction with the original
temperature/signal cross-covariance. Noise enters the signal covariance once.
Numerical/upper/lower sets are disjoint; flag entries contain NaN rather than
numerical readings. This does not clip latent temperatures, impose a hard `T<c`
constraint, independently truncate pixels, or reweight cached marginal draws.
Area weights enter evaluation only, not likelihood factors.

Interpretation, without declaring a universal winner:

**A. Unused-region improvement:** mask-only information lowers RMSE and CRPS in
both cases. The frozen approximate model does not make numerical readings a
guaranteed realized-error bound: Cmask has slightly lower pool RMSE, whereas
Cnumeric has substantially lower pool CRPS and bias.

**B. Beyond added locations:** at the remaining unused nodes, diagonal RMSE/CRPS
change from 0.3251/0.2011 to 0.2284/0.1872; spiral changes from 0.4138/0.2260 to
0.2849/0.1984. Thus the effect extends through spatial dependence beyond U.

**C. Not simply narrower intervals:** unused-pool widths decrease slightly under
Cmask, while error and CRPS decrease and coverage increases. Coverage is already
above 95% in this region, so this is not evidence of perfect calibration. At the
diagonal hot area, however, narrower intervals accompany worse CRPS and coverage.

**D. Numerical-information control:** numerical readings give larger unused-region
CRPS improvements and much narrower intervals than flags at the same locations.
This control was run for the primary seed only, not both repeats.

**E. Higher-ceiling redundancy:** not experimentally established here. The preset
reference reliability gate failed, so no 320/325 K posterior updates were run.
At reference, most U flags are already compatible with C0, but a minority are not:
217/256 diagonal and 206/256 spiral locations have baseline flag probability
above 0.99, while 12 and 20 respectively have probability below 0.5. These are
descriptive probabilities averaged over baseline latent draws, not selection
criteria. A high-ceiling effect cannot be inferred from this alone.

**F. Remaining peak:** neither addition fixes the extreme peak. At the true peak
node, C0/Cmask/Cnumeric signed errors are 10.454/10.589/10.328 K (diagonal) and
22.892/23.087/22.966 K (spiral); all three intervals miss truth. Small differences
at one peak should be read alongside repeat-seed variability, not as precise
improvements. `peak_absolute_error_K` in the detailed table separately compares
the reconstructed maximum with the true maximum; it is not the same metric as
error at the true-peak node.

## Reliability and computational scope

Four current chains use 400 retained HMC states after 100 burn-in steps, thinning
1. The historical classical-R-hat screen is 1.05, with the unchanged optional
800/300 retry. Evaluation uses 300 states per chain (1,200 pooled marginal
draws). C0 and Cmask also receive an additional paired seed offset of 7,000,019;
the previous posterior remains fixed. Chain identities, noisy constrained
variables, and monitored latent temperatures are saved.

The predeclared expansion gate requires every arm/repeat to have maximum
rank-normalized split R-hat <= 1.01, minimum bulk/tail ESS >= 400, classical
R-hat <= 1.05, runtime <= 300 seconds/arm, and process peak RSS <= 4 GiB. It is
stricter than the inherited screen and was not relaxed. See
[gate](reference_gate.json), [all diagnostics/runtime](reference_convergence_runtime.csv),
and [paired repeat differences](repeat_seed_comparisons.csv). Gate failure blocks
higher-ceiling fits even if observed metric effects are promising. Two seeds
are a stability check, not a formal confidence interval or convergence proof.

All ten fits passed the inherited classical screen without retries. Three
arm/repeat combinations failed the stricter expansion gate: diagonal Cmask seed
0 had maximum rank R-hat 1.01132; spiral C0 seed 0 had 1.01119; spiral Cnumeric
seed 0 had minimum bulk ESS 345.76. Other minimum bulk ESS values were at least
688.82; minimum tail ESS across all fits was 879.16. These modest misses do not
establish that the effects are artifacts, but they prevent declaring the pilot
fully reliable under the preset rule. No high-ceiling fit was run.

Unused-pool paired Cmask-minus-C0 changes were stable across seeds:

| Case | RMSE change, seed 0 / seed 1 | CRPS change, seed 0 / seed 1 |
|---|---|---|
| Diagonal 8 | -0.07859 / -0.08006 | -0.00987 / -0.01058 |
| Spiral 13 | -0.10606 / -0.10539 | -0.01943 / -0.01922 |

The hot-area CRPS worsening in diagonal and improvement in spiral also persist
across seeds. However, spiral hot-area coverage changes +0.02257 in seed 0 but
-0.00174 in seed 1: its small coverage benefit is **inconclusive**. True-peak
interval-width changes are likewise not stable relative to repeat variability.

Measured per-fit runtimes (sampling plus diagnostics, excluding cache writing
and prior-block preparation) were 14.5-20.4 s for C0, 71.6-151.5 s for Cmask,
and 24.4-35.5 s for Cnumeric. The ten fits total 596.4 s, approximately 9.94
minutes; this is not the total end-to-end task time. Maximum process high-water
RSS recorded after fits was 2,871.5 MiB (2.80 GiB), not isolated per-arm memory.
Mask-only information was substantially more expensive than numerical readings
here because it enlarged the constrained block.

|---|---|---|---|

The unused pools contain 4,969 and 4,918 nodes, covering 84.26% and 84.14% of
surface area. Selected-node lumped areas are 27.29% and 27.38% of the domain;
nearest-selected-node Voronoi assignments cover the entire eligible pool. Those
two notions of represented area must not be confused. Neither weights the
likelihood. IDs, coordinates, node areas, and assigned pool areas are saved in
each trajectory's `selected_locations.csv`.

[Preflight estimates](preflight.csv) cover dimensions and dominant array storage
before inference, including an explicitly **NOT RUN** all-omitted expansion.
That expansion would involve 6,275 observations and 6,160/6,161 constraints;
core arrays alone were estimated at approximately 1.1 GiB, before workspaces and
other resident caches. Cubic work ratios and rough runtime estimates are not
measured full-mask benchmarks. No such expansion was launched.

## Limitations and provenance

This is a two-case development pilot under the inherited approximate prior, not
a 30-trajectory generalization result. Previous unsaturated noisy values remain
pinned; previous sampled marginal fields are not automatically coherent joint
latent draws. Current predictions also retain historical marginal residual
sampling rather than full joint posterior fields. Rank/ESS checks diagnose the
sampled target; they do not establish physical correctness or calibration.

`HeatFluxZ` remains the supplied projected vertical temperature gradient; the
historical numerical gradient contribution and threshold were not reinterpreted
or changed. The inherited output-49 configuration includes stale grid metadata
such as `exact hottest 25 of 2501 pixels` and broad A/B/C labels. They are retained
verbatim inside `inherited_settings`, **not** descriptions of the executed native
area-weighted C-only pilot. No pseudo-censoring calibration was fitted/applied.

CRPS preserves the existing `M(M-1)` pair-dispersion convention. Its formal
unbiasedness assumes independent draws; these are MCMC draws, and spatial nodes
are not independent replicates. Marginal 95% intervals are not simultaneous
field bands. See the [censoring likelihood reference](https://mc-stan.org/docs/stan-users-guide/truncation-censoring.html)
and [rank/ESS diagnostic reference](https://mc-stan.org/docs/reference-manual/analysis.html).

temporary dependency directory is not part of the snapshot or repository and
must be provisioned separately on another machine.
