uses output 38's prepared ceiling schedule; driver 41 reads output 30

## 3. Previous estimate, deterministic mean and current prior

- [thermal_posterior_physics.py, `previous_posterior_observations`, 221-244](../../src/thermal_posterior_physics.py#L221): numerical candidates union previous observed-censored mask, prediction at censored nodes only.
- [`infer_previous_censored_posterior`, 247-301](../../src/thermal_posterior_physics.py#L247): ambient RBF; full camera array is copied across draws, censored entries overwritten with sampled latent marginal predictions, previous mean computed from these draws. Truth is used for diagnostic errors, not this likelihood. The coherent alternative at 304-375 is **not called**.
- [censored_gp.py, `sample_censored_ess_fast`, 92-244](../../src/censored_gp.py#L92): despite the name, caller selects HMC. Conditions noisy saturated signals on selected noisy numerical observations. Final Gaussian conditional residuals are drawn independently by prediction location; therefore marginal correctness does not imply coherent joint fields. `sample_multiple_chains` 247-285 uses seed offsets of 10000.
- [matched_projection.py, `MatchedHeatOperator`, 47-97](../../src/matched_projection.py#L47): native `N` triangle lift or projected `R P` lift, Gaussian diffusion/cooling, bilinear native evaluation `E`. Mean is `ambient + E G floor(N(previous-ambient),0) + gamma*g*1[g>=10000]*dt` for native inputs. Zero extension is used, no advection in the four scoped outputs. Source thresholding occurs after a coarse round trip only for output 49's projected control.
- Same class `propagate` 66-91: covariance deviations use `floor=False`, no source and no displacement. This is a linear map A; it is not the nonlinear floored mean operator applied to each sample. It does not propagate uncertainty in alpha/beta/gamma.
- [censored_gp.py, `rbf_covariance`, 37-46](../../src/censored_gp.py#L37): B covariance is `signal_sd**2 * exp(-distance_xy**2/(2*lengthscale**2))`; time coordinate ignored.
- [stochastic_heat_gp.py, `stochastic_heat_covariance`, 36-84](../../src/stochastic_heat_gp.py#L36): free-space stationary covariance evaluated by 24-point Gauss-Laguerre mixture and normalized at zero lag. `finite_step_innovation_covariance` 123-150 subtracts lag `2*dt` from lag zero. No advection path passed.
- Driver 53 `main` 151-171, driver 56 `main` 185-195, driver 57 `main` 76-119: `features = A(draws-mean).T / sqrt(S-1)`; `Koo = Qoo + Hobs Hobs^T`, `Kpo = Qpo + Hpred Hobs^T`, diagonal `qdiag + sum(Hpred**2)`. Driver 57 recomputes the same blocks for additional observation locations. This is **not** `sequential_moment_matched_covariance` (87-120 in stochastic_heat_gp.py), nor `native_surface.propagate`'s alternative native FEM operator.

Write ell for the forcing length and `a_j,w_j` for Laguerre nodes/weights.
The normalization is `Z = sum_j w_j*ell^2/(ell^2+2*alpha*a_j/beta)`.
Under the stationary RBF-forcing interpretation, the corresponding continuous
forcing covariance amplitude is `sigma_W^2 = 2*beta*signal_sd^2/Z` (K2/s),
using this numerical quadrature. It is **derived**, not an independent fitted
`sigma_W`. Q_dt is a covariance in K2, not this covariance rate; shared
`signal_sd` does not make B and C predictive marginal variances equal.
Q_dt uses free-space physics whereas A uses interpolation and zero-extension
boundaries: this is the implemented approximate construction, not a claimed
exact discretization of one native-mesh SPDE.

## 4. Current likelihood, sampling and scoring

- [pseudo_censoring_runner.py, `_previous_prediction`, 106-169](../../src/pseudo_censoring_runner.py#L106) and [`_current_prediction`, 43-103](../../src/pseudo_censoring_runner.py#L43): explicit executed HMC options override sampler function defaults. One fresh retry on failed R-hat, then error, not silent acceptance. Current wrapper receives current-only observation dictionary.
- [dense_censored_gp.py, `sample_censored_gaussian_blocks`, 200-349](../../src/dense_censored_gp.py#L200): `noisy_oo = Koo + (noise_sd**2 + jitter) I`. Unsaturated values contribute Gaussian density; saturated noisy latent signals are truncated above c, equivalent to the integrated noisy censoring likelihood. Prediction concerns latent T. No additional upper-mask factor or second likelihood for exact values.
- [truncated_gaussian.py, `sample_lower_truncated_gaussian_hmc`, 75-149](../../src/truncated_gaussian.py#L75): analytical harmonic motion/reflection after Cholesky whitening; initial censored signal `max(location, bounds + .5*sqrt(max(diag(cov),1e-12)))`. Travel times uniform `[pi/4,3*pi/4]`; no adapted HMC stepsize, mass fit or optimizer restart.
- [mcmc_diagnostics.py, `gelman_rubin` / `chain_diagnostics`, 6-55](../../src/mcmc_diagnostics.py#L6): classical per-target R-hat and chain-mean deviations. Zero within-variance <=1e-14 yields NaN excluded by nan reductions; no native saved ESS/autocorrelation or initialization-sensitivity study.
- [pseudo_censoring_runner.py, `prediction_from_draws` / `_balanced_draw_subset`, 19-40](../../src/pseudo_censoring_runner.py#L19): 300 evenly spaced retained draws per chain, pooled mean, SD with ddof=1, 2.5/97.5% quantiles. Native callers do not supply full `prediction_covariance`; current draws also have independent conditional marginal residual noise.
- [matched_projection.py, `weighted_metrics`, 100-114](../../src/matched_projection.py#L100), [native_surface.py, `hottest_area_weights`, 83-93](../../src/native_surface.py#L83): lumped physical area and fractional final weight for exactly 1% area. [metrics.py, `empirical_crps`, 10-27](../../src/metrics.py#L10) uses M(M-1); unbiasedness requires independent draws, not automatically satisfied by MCMC. No interval inflation in scoped runs.

Seeds: catalog zero-based indices are 7 (diagonal) and 32 (spiral).
Camera seed = 41+10000*i; previous = 41+50000*i; current = 41+100000*i.
Previous chain offset is **10000**, current offset **100000**; each HMC call
adds 1000003 internally. Seeds are held across B/C and ceilings, not independent
camera redraws. Same seed with different observation dimension does not imply
identical sample paths.

- [diffusion.py, `estimate_effective_diffusivity`, 55-152](../../src/diffusion.py#L55): full projected development histories, ambient global 2% quantile, negative forward rate, excess >=0.5 K, interior Laplacian, abs(previous gradient)<300. Up to 250000 samples, RNG seed0 if capped. Minimize sum `(dT/dt-alpha*laplacian+beta*excess)^2`. Normalize columns/response for algebra; solve unconstrained interior, nonnegative axes and zero, select least residual. Alpha/beta nonnegative, no upper bound/log transform/iterative initialization. Native preparation repeats diagnostic fits but discards their fitted coefficients.
- [thermal_posterior_physics.py, `build_calibration_components`, 549-575](../../src/thermal_posterior_physics.py#L549) and [`calibrate_source_coupling`, 578-591](../../src/thermal_posterior_physics.py#L578): clipped noise-free predecessors, all active-source frame/pixel pairs, target simulator excess minus propagated background, `gamma=max(s dot target/(s dot s),0)`; no initial guess, restart, optimizer or upper bound. Counts 2880/3507/4780. Median gamma is the diagonal fit. Not fitted on previous-posterior draws.
- Signal SD: median across development `cooling_excess_q95_K`; not residual SD optimization. Source length: median weighted gradient-footprint width floored by grid spacing, then multiplier; no length optimization in native runs.
- [Driver 18 `SENSITIVITY_SETTINGS`, 53-79](../../scripts/18_thermal_two_frame_ablation.py#L53), [`run_sensitivity`, 410-495](../../scripts/18_thermal_two_frame_ablation.py#L410): finite 16-setting development search over signal/noise/beta/length multipliers, old physics-mean+space-time model at 3%; coverage >=0.85 eligibility (fallback all settings), lexicographic hot CRPS then interval score. Base multipliers 1; no gradient optimizer/log parameters. Original selected/search CSVs absent; the then-executed scoring revision and winning run cannot be certified from present code alone.
- [Driver 19 `load_selected_configuration`, 133-157](../../scripts/19_thermal_corrected_crps.py#L133): absent-file fallback signal1/noise2/beta1/length1.25. Later driver26 explicitly defaults to the same current scale/length values. This is evidence of inherited settings, not proof a surviving optimization selected them. Script16's `select_lengthscale` unsaturated-NLL search is not called by native reconstruction.
